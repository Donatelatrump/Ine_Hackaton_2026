# Track 3: Comunicación y visualización con impacto público

Storytelling educativo: definir mensaje/público, narrativa veraz, prototipo funcional y difusión; comparar indicadores temporales y territoriales priorizando precisión.

Entregables: prototipo PDF/PNG/web; guion PDF de 3–5 cuartillas; pitch MP4, 1080p, máximo 3 minutos, accesible mediante Vimeo, YouTube oculto o Drive/OneDrive.

Consulta el desarrollo completo del reto en las páginas 3–4 y sus entregables en la página 5 de la [convocatoria oficial](https://ine.mx/wp-content/uploads/2026/09/Convocatoria_Hackaton-1.pdf).

Los requisitos y recursos compartidos están en [RECURSOS.md](RECURSOS.md).
