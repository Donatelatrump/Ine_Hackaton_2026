# Fuentes de información · Umbral

Proyecto **Umbral**, equipo **Aguas.exe**. Se conservan los nombres y formatos originales de los insumos para mantener su trazabilidad.

| Carpeta | Uso |
| --- | --- |
| `Bases_de_datos_explicativos/` | Bases de contexto demográfico y explicativo. |
| `Datos_propuestas_estatales/` | Planes, encuestas y estudios de las fichas y propuestas estatales. |
| `Otras_fuentes_de_informacion/` | Estudios, tesis y páginas consultadas con sus recursos locales. |
| [Documentos oficiales](../umbral/documentos_oficiales/) | Material oficial y bases del reto. |
| [Cartografía](../umbral/cartografia/) | Insumos geográficos y herramientas de preparación. |

Consulta [las fuentes complementarias](../docs/FUENTES_COMPLEMENTARIAS_UMBRAL.md), [las fichas estatales](../umbral/demo/FICHAS_ESTATALES.md) y [la metodología](../umbral/modelado/METODOLOGIA.md) para conocer el uso y las limitaciones de cada insumo. La aplicación enlaza las fuentes locales desde las fichas.
