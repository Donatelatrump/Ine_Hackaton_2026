# Aplicación Umbral · Aguas.exe

Abre [el acceso principal](../../index.html) o [la aplicación](demo7.html).

- `demo7.html`: interfaz vigente.
- `assets/`: JavaScript y CSS compilados.
- `data/`: datos precalculados y cartografía local.
- `vendor/`: Leaflet y sus recursos locales.
- `images/`: imágenes de la interfaz.
- `src/demo7/` y `styles/demo7.css`: fuentes específicas de la versión actual.
- `src/demo6/` y `styles/demo6/`: módulos compartidos necesarios para construir la versión actual.
- `build.demo7.config.json`: orden de compilación.

Desde la raíz: `python umbral/tools/construir_demo7.py`.

Consulta la [guía funcional](DEMO7.md), las [fichas y fuentes](FICHAS_ESTATALES.md) y el [README de entrega](../../README.md).
