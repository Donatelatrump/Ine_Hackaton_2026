# Reporte metodológico y preventivo — Umbral

Actualizado el 22 de octubre de 2026. [PDF de 14 páginas](Umbral_reporte_metodologico_preventivo.pdf), [fuente Markdown](Umbral_reporte_fuente.md) y [generador](generar_reporte.py). Modificar el generador y regenerar; el Markdown y PDF son salidas.

La convocatoria del Reto 2 pide 10–15 cuartillas y no define la unidad. Este reporte interpreta una cuartilla como una página carta. Incluye variables históricas y sociodemográficas, selección retrospectiva de cuatro modelos, semáforo relativo, comparación de escenarios y recomendaciones de prevención y recursos. Sus capturas proceden de `demo/verificacion/demo7/`.

El plan estatal supuesto (10% de cobertura; 1.5 pp entre alcanzados) se distingue del caso municipal SMS y su coeficiente externo. Los datos del experimento del 16 de octubre no se reentrenaron. La proyección 2027 no está validada con una elección futura.

Seguir el [orden de regeneración](../README.md); primero verificar Umbral para actualizar las capturas. El generador verifica páginas, límites y texto y guarda [evidencia](verificacion.json) y vistas en `revision_visual/`. `entrega/verificar_entrega.py` comprueba además cifras, superposición de texto y correspondencia con la prueba web vigente.

[Requisitos oficiales, evidencia y pendientes](../REVISION_REQUISITOS_INE.md). Registro, elegibilidad, cartas y envío no se acreditan mediante el reporte.
