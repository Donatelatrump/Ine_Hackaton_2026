# Archivo de depuración

`depuracion/` conserva capturas, copias anteriores, páginas de reproducción y registros que antes estaban junto a las páginas activas. No se cargan desde demo6.

Son instantáneas históricas: sus rutas relativas pueden corresponder a la ubicación antigua. No se consideran herramientas ejecutables actuales. Los scripts de comprobación y sus comandos permanecen en sus ubicaciones originales.

El registro de movimientos está en `../../arquitectura/migracion_demo6.json`; no se borraron estas evidencias.
